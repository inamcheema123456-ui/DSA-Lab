# DSA-Lab
Data Structures and Algorithms (DSA) Lab assignments containing programming tasks and implementations completed as part of the course.
📚 DSA Lab

Welcome to my Data Structures and Algorithms (DSA) Lab repository.

This repository contains the programming assignments completed as part of the DSA Lab course. All programs are implemented in Java and focus on understanding and applying fundamental data structures and algorithms.

📌 Assignments

🔹 Assignment 1

Assignment 1 covers the following fundamental data structures:

- Array
- Stack
- Queue

These programs demonstrate the basic operations and working concepts of each data structure using Java.

🔹 Assignment 2

Assignment 2 includes implementations of arrays and linked-list-based data structures:

- 2D Array
- Simple Linked List
- Doubly Linked List
- Stack Using Linked List
- Queue Using Linked List

These programs provide practical understanding of different ways to store, organize, and manage data using Java.

💻 Programming Language

Java

🎯 Purpose

The purpose of this repository is to practice and demonstrate fundamental Data Structures and Algorithms through hands-on Java programming.

It includes implementations of both basic array-based structures and linked-list-based structures, helping to understand their working, operations, and practical usage.
